EG40

QRコードの赤い口を持った、いまのJR東日本の改札機。

2022年12月11日、代々木駅。老朽化したEG20の置き換えとして最初の1台が動き出した。 磁気券・交通系IC・QRコードの三つを一台で受ける、JR東日本メカトロニクス製の自動改札機である。

01 — 沿革

置き換えは、ひとつの駅から始まった

EG40は新機能のための新型機であると同時に、耐用年数を迎えたEG20の後継でもある。だから展開は「線」ではなく「点」で進み、いま気づけば首都圏でも地方でもこの顔になっている。

2022.11.08

QR乗車サービスを発表

JR東日本が、えきねっとで購入した乗車券をスマホのQRコードで使える構想を公表。あわせて、老朽取替に合わせてQRリーダー搭載の新型改札機を順次設置すると告知した。

2022.12.11

代々木駅で第一号機が稼働

山手線・中央総武線各駅停車の代々木駅に設置。この時点ではQR乗車は未開始で、赤い読取口は黒いフタで塞がれていた。

2022.12.18

東大宮駅（宇都宮線）

都心以外への設置も同月中に始まる。首都圏中心という当初の予想を早々に裏切った。

2023.03.18

幕張豊砂駅、開業時からEG40

京葉線の新駅。最初からこの機種で揃えられた、いわば「EG40ネイティブ」な駅のひとつ。

2023.12.24

武蔵小杉駅 綱島街道改札

新設改札口に開業時から採用。既存駅の改良でも新設側から入っていくパターンが定着する。

2024年度下期

東北エリアでQR乗車を開始

赤いフタが外れる。えきねっとで予約した乗車券・特急券を1つのQRに集約し、在来線と新幹線をまたいで通過できる運用が始まった。

現在

エリアを問わず置き換えが進行中

仙台空港駅のような地方の駅から東京駅まで。利用の少ない駅にはドアのない仕様も設置され、EG20を見かける機会は着実に減っている。

02 — 意匠

見分け方は、だいたい上面に出ている

遠目にはどれも同じ灰色の箱に見えるが、EG40はEG20から造形をかなり動かしている。ホームに降りたとき何を見ればいいか。

POINT / 01

赤いQRコード読取口

最大の識別点。灰色の筐体に赤が一箇所だけ差さる。サービス開始前は黒いフタで覆われていたため、フタの有無で設置時期の当たりがつく。

POINT / 02

うねるICリーダー面

EG20の平坦な面に対し、Suicaを当てる部分に大きな起伏がある。エッジを立てつつ曲線でつなぐ処理で、手が自然に降りる位置を作っている。

POINT / 03

表示パネルの集約

EG20では残高表示器とエラー表示器が別々の位置に分かれていた。EG40は従来のエラー表示器の位置に一枚のパネルとしてまとめている。

POINT / 04

ドアなし仕様

利用者の少ない駅では、フラップドアを持たない構成で設置される。通り抜けは自由で、無効時に音と表示で知らせる運用。

POINT / 05

通称「虹」の継承

改札の不正通過対策としてJRの改札機に多数設置されている検知機構。EG40も引き続き採用しており、鳴動条件は従来どおりだが音質が大きく改善された。

POINT / 06

三媒体対応

磁気券の投入口、交通系ICのリーダー、QRの読取口を一台に同居させている。過去・現在・これからが一つの上面に並んでいる。

04 — QR乗車のしくみ

紙にもICにも記録しない。判定はサーバにある

磁気券は券面裏の磁気層に、ICカードはチップに情報を持つ。QR乗車はどちらでもない。改札機は読み取った情報をその都度センターサーバに問い合わせ、有効かどうかの答えを受け取る。

えきねっとで購入

乗車券と特急券をまとめて予約。予約情報がセンターサーバへ連携される。

アプリにQRを表示

同じ区間でも発行のたびに異なる固有のコードが生成される。使い回しはできない。

改札機で読み取り

赤い読取口にかざす。乗車券と特急券の効力を同時に判定するため、乗換改札も1つのコードで通れる。

サーバが都度判定

QR対応の改札機はすべてセンターサーバに接続され、通過した情報はリアルタイムで把握されている。

05 — 界隈用語

改札機まわりで飛び交う言葉

改札機の話題を追っていると、辞書に載っていない言い回しに何度もぶつかる。ここでは意味と出どころを整理する。ただし、そのうちいくつかは犯罪の呼び名である。

このページの方針

不正乗車の手口そのものは掲載しません。「何を指す語か」「法的にどう扱われるか」だけを記録します。無賃乗車は鉄道営業法第29条の対象で、悪質な場合は刑法246条の詐欺罪にあたります。加えて運送約款により、運賃と2倍の増運賃、合わせて3倍相当額を請求されます。実際に逮捕・書類送検された例もあります。

尖閣せんかく不正乗車の隠語

自動改札機のセンサーを塞いで通過する無賃乗車の手口を指す語。「センサーを隠す」を略した「セン隠（せんかく）」に、同音の「尖閣」を当てたもの。地名とは関係がない。

誤解されがちだが鉄道趣味者の用語ではない。主な使用層は音楽ゲーム界隈などで、未成年の比率が高い場に「ゲームの裏技」めいた感覚で広まった経緯がある。撮り鉄の迷惑行為と結びつけて語られることがあるが、由来としては別筋である。

幹脱かんだつ要検証

「幹（新幹線）」＋「脱（脱出）」の略とみられ、新幹線改札での不正出場を指す語として同じ界隈で使われている。ただし、辞書・報道・研究のいずれにも定着した記述が見当たらず、定義に揺れがある。

本サイトでは裏取りできていない語として扱う。確度の高い一次情報をお持ちの方は連絡してほしい。

虹にじ通称・一般

改札の不正通過対策としてJRの改札機に多数設置されている検知機構の通称。隠語というより、ファンのあいだで普通に通じる呼び名。EG40も継承しており、鳴動条件は従来機と同じまま音質が改善された。

キセルきせる不正乗車の俗称

両端だけ運賃を払い、中間区間の運賃を免れる古典的な不正乗車。煙管が「両端が金属、中間は竹」であることに由来する。

薩摩守さつまのかみ不正乗車の符丁

無賃乗車を指す古い言い回し。薩摩守だった平忠度（たいらのただのり）の名を「ただ乗り」に掛けた洒落で、狂言の演目名としても知られる。

EG20 / EG40いーじーにじゅう・よんじゅう機種名

JR東日本メカトロニクス製の自動改札機の機種名。ファンのあいだでは駅名と機種名をセットで語るのが常で、「◯◯駅がEG40に更新された」という報告がSNSに日々流れている。
